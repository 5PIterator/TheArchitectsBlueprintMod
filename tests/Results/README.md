# Test results

Generated by `/tab.test` and Debug Stick **TST**. Payload scenarios are generated for every `*.tab.json` in `tests/Samples/`. Each run writes:

- `latest.txt` — human-readable summary
- `latest.json` — machine-readable summary
- `run_YYYYMMDD_HHmmss.txt` / `.json` — archived copy of that run

When running from a ModSources build, files land here. Otherwise they are written under the mod save folder (`TheArchitectsBlueprintMod/test-results/`).
