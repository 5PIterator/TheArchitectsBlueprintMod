# The Architect's Stencil

## Overview
The Architect's Stencil (`ArchitectsStencil`) is a Terraria mod that lets you capture a region of the world as a *Blueprint* and place copies of it elsewhere using the materials you already own. It focuses on intuitive selection tools and clear visual feedback so larger builds feel fast instead of fiddly.

## Core Concepts
- **Blueprint**: The region you select that The Architect's Stencil will work with.
- **Projection**: A movable ghost of a Blueprint that shows where the structure will be built.
- **Tools**: A family of sticks and wands that handle selecting, editing, copying, cutting, and pasting structures.

## Features
- **Selector Stick (PIN stick)**: Pin a new Blueprint selection (always starts fresh) and quickly RESET it.
- **Add / Remove Sticks**: Refine either a Blueprint or its Projection by including or excluding tiles.
- **Copy / Cut Sticks**: Create Projections of a Blueprint that can be moved and reused.
- **Paste Stick**: Convert a Projection into real blocks, using materials from your inventory or nearby chests.
- **Combined Wands**: Progression into the `Blueprint Wand` (SET/RESET), `Stencil Wand` (ADD/REMOVE), `Projection Wand` (COPY/CUT/PASTE), and finally the **Architect's Stencil** and **Architect's Soul**, which bundle multiple actions into a single late-game tool.

## Material Usage
- Pasting uses items from your inventory or an inventory adjacent to either the Blueprint or the Projection.
- Copy-based pasting keeps the original structure intact.
- Cut-based pasting removes the original Blueprint and uses its items to build the Projection.

## Installation
1. Ensure you have tModLoader installed.
2. Download **The Architect's Stencil** from the in-game Mod Browser or your chosen source.

## Usage
- Use the **Selector Stick** (PIN) or **Blueprint Wand** (SET) to create, resize, and move a Blueprint region.
- Use **Add** and **Remove** sticks (or the **Stencil Wand**) to fine-tune which tiles belong to the Blueprint or Projection.
- Use **Copy** or **Cut** sticks (or the **Projection Wand**) to create and move Projections.
- Use the **Paste Stick** or the all-in-one **Architect's Stencil** to consume materials and build the Projection into the world.
